01BACKEND · DISTRIBUTED SYSTEMS

HookFlow

Reliable webhook and event delivery.

Persists each event and its first delivery record in one PostgreSQL transaction before acknowledging ingestion. Redis acts as a wake-up hint, while workers independently poll due rows. Lease claims and expiry recovery protect against worker crashes; idempotency constraints guard concurrent producer retries.

Engineering highlights Database-enforced idempotency · FOR UPDATE SKIP LOCKED claim-and-lease workers · HMAC-SHA256 signatures · encrypted endpoint secrets · exponential backoff · dead-letter replay · correctness tests.

05SYSTEMS · ANDROID · LINUX

Tuxport

A Linux terminal environment running on Android without root.

Bundles Alpine Linux and runs unmodified ARM64 Linux binaries inside an Android app process. Its runtime combines a CPU translation engine, a user-space Linux syscall layer and Ghostty's terminal implementation.

Engineering highlights Android + Rust workspace · ARM64 execution path · interpreter fallback · terminal integration · package management · background process notifications · differential tests and documented architecture.
