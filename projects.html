Projects

  • Lexora

    Document Q&A backend with cited sources. Uploads are validated, chunked, and embedded into per-user FAISS indexes so queries never cross tenants; ingestion runs through Celery, retrieval is cached in Redis, and answers stream over SSE alongside the chunks that grounded them.

    python · fastapi · postgresql · redis · celery · faiss · 35 tests

  • HookFlow

    Persist-first webhook delivery. Events and delivery rows commit before any dispatch attempt; workers claim due rows with expiring leases (FOR UPDATE SKIP LOCKED), sign payloads with HMAC-SHA256, and retry with exponential backoff before moving exhausted deliveries to a replayable dead-letter queue.

    python · fastapi · postgresql · redis · next.js · 79 tests · 93% coverage

  • EsenceLab

    Multi-service hiring platform across a Next.js frontend, an Express API with JWT auth and gated recruiter RBAC, and a FastAPI service for PDF resume parsing and job matching. Scoring is deterministic first (skill overlap + TF-IDF) with an optional LLM assist and local fallback.

    typescript · next.js · express · fastapi · postgresql · docker

  • neuDB

    Zero-dependency embedded database in pure Python. Each table is a human-readable JSON file, writes are crash-atomic (temp file, fsync, atomic replace), and text and cosine similarity search run in the standard library—with the ~10K-row-per-table ceiling stated up front.

    python · stdlib only · 32 tests · promo site
